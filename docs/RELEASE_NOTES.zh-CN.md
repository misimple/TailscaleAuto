# Tailscale Auto 1.6.14.0-dev — 预览版说明草稿

此 Windows 预览版集中显示 Tailscale 设备、在线状态、最近一次直连或中继路径与延迟，支持复制 IP、远程桌面快捷入口、英文和简体中文、悬浮窗及托盘运行。局域网 RDP 只在确认物理局域网路由和 TCP 3389 后启用，点击时重新验证。

运行前请安装并登录 Tailscale。ZIP 含 EXE、中英文使用说明和 MIT 许可证。EXE 尚无受信任代码签名。此候选已通过自动化和模拟集成测试，**新版 LAN RDP 尚未完成真实双机局域网复验**。本项目为独立开发的非官方辅助工具，不受 Tailscale 官方支持。
