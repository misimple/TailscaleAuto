# Tailscale Auto 1.6.14.0-dev — First Public Preview

This Windows preview shows Tailscale devices, online status, the latest direct or relay path and latency, and shortcuts for Copy IP and Remote Desktop. It supports English and Simplified Chinese, a floating monitor, and tray operation. LAN RDP is enabled only after the app verifies a physical local route and TCP 3389, and is rechecked on click.

Install and sign in to Tailscale before running `TailscaleAuto.exe`. LAN RDP requires LAN connectivity, Remote Desktop enabled on the target, and reachable TCP 3389. The ZIP contains the EXE, bilingual instructions, and MIT LICENSE. The EXE is not signed by a trusted publisher. Release-preparation automated and simulated integration checks passed. The user reports successful Tailscale RDP and LAN RDP connections on multiple real Windows devices; no separate live acceptance record tied specifically to the 1.6.14.0-dev build is available. This is an independent, unofficial companion, not supported by Tailscale.
