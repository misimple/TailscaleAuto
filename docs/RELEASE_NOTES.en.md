# Tailscale Auto 1.6.14.0-dev — preview draft

This Windows preview shows Tailscale devices, online status, the latest direct or relay path and latency, and shortcuts for Copy IP and Remote Desktop. It supports English and Simplified Chinese, a floating monitor, and tray operation. LAN RDP is enabled only after the app verifies a physical local route and TCP 3389, and is rechecked on click.

Install and sign in to Tailscale before running `TailscaleAuto.exe`. The ZIP contains the EXE, bilingual instructions, and MIT LICENSE. The EXE is not signed by a trusted publisher. This candidate passed automated and simulated integration tests; its LAN RDP integration has not yet passed a new live two-device LAN test. This is an independent, unofficial companion, not supported by Tailscale.
