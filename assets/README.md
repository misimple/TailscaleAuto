# Generic device pictograms

`windows.png` is a generic desktop monitor, `ios.png` a generic phone, and `android.png` a generic tablet. The filenames are compatibility keys used by the existing UI source; the artwork contains no Windows, Apple, or Android logo.

All three 128×128 transparent PNGs are generated by `GenerateGenericIcons.cs`, created specifically for this project. Copyright (c) 2026 MiSimple. Licensed under the repository's MIT License. No third-party artwork is incorporated.

Run `powershell -ExecutionPolicy Bypass -File .\generate-icons.ps1` on Windows to regenerate the PNGs.
